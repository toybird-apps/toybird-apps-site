Frequently Asked Questions

The ring does not appear when I press Command

Open System Settings → Privacy & Security → Input Monitoring, enable Pointer Cue, then quit and reopen the app.

How do I outline an area?

From Range Selection in the menu bar, choose Command + Drag, Control + Command + Drag, Option + Command + Drag, or Off. Hold the selected shortcut and left-drag to draw a temporary rectangle. The rectangle gradually fades out.

How does Focus Cue work?

Enable Highlight Active Window. The active top-level window remains clear while the rest of that display's usable area is covered by a 50% translucent white mask. Masked areas remain fully operable, and the menu bar and Dock stay clear.

What happens with multiple displays?

Focus Cue applies only to the display containing the active window. Other displays remain unmasked. If an active window spans displays, Focus Cue applies only to displays containing that window.

Does Focus Cue follow window switching?

Yes. It follows normal macOS switching and selection, including Command + Tab, window cycling, clicks, Dock, Stage Manager, Mission Control, and Finder Quick Look. During a move or resize, the mask temporarily disappears and returns at the final stable position.

How do I change the cue color?

Open the Pointer Cue menu-bar item and choose a preset or custom color from the Color submenu.

How do I change the display language?

Open the Pointer Cue menu-bar item and choose a language from the Language submenu. By default, Pointer Cue follows your macOS preferred language.

How do I turn off Launch at Login?

Open the Pointer Cue menu-bar item and disable Launch at Login.

Does Pointer Cue need Screen Recording permission?

No. Pointer Cue does not capture or transmit your screen content. Input Monitoring is used only for the local key and mouse state needed by its cue gestures.

Which macOS versions are supported?

Pointer Cue supports macOS 13.5 or later.
