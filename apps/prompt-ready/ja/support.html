ChatGPT版

ChatGPT版では、ChatGPT内で用途に合ったワークフローを選び、表示された条件を設定し、元の文章や背景情報を追加して、そのままChatGPTの会話を続けられます。

Toybird Labs独自のアカウント登録は不要です。表示言語、ワークフロー条件、出力言語、最近使用したワークフローIDなど、一部の設定はローカルに保存される場合があります。

Windows / macOS版

  1. Prompt Readyを開き、行いたい作業の種類を選びます。
  2. 元の文章、テーマ、背景情報を貼り付けるか、直接入力します。
  3. 必要に応じて表示された設定を調整します。
  4. 作成されたAI向け依頼文を確認します。
  5. 依頼文をコピーを押し、利用するAIサービスへ貼り付けます。

よくある質問

Toybird Labsのアカウント登録は必要ですか？

いいえ。Prompt ReadyはToybird Labs独自のアカウント登録やログインを必要としません。

ChatGPT版は無料ですか？

Prompt Ready for ChatGPT v1.0は、Prompt Ready独自のサブスクリプションなし・画面内の第三者広告なしで無料提供する予定です。

ChatGPT版に入力した内容をToybird Labsが保存しますか？

入力した本文やChatGPTの回答をToybird Labsのユーザーデータベースへ保存しない設計です。ChatGPTへ送信した情報は、OpenAIの利用規約とプライバシーポリシーに基づいてChatGPT側で処理されます。

Recentには何が保存されますか？

素早く再利用できるよう、直近で使用したワークフローのIDを短い一覧として保存する設計です。入力した本文やChatGPTの回答をRecentへ保存するものではありません。

表示言語と出力言語を変更できますか？

はい。対応している画面では、表示言語と出力言語を個別に選択できます。次回起動時に復元できるよう、これらの設定をローカルに保存する場合があります。

デスクトップ版の対応OSは？

WindowsとmacOSに対応します。macOS版はmacOS Ventura 13以降が必要です。

独立した製品です

Prompt ReadyはToybird Labsが独立して提供する製品であり、OpenAI、Anthropic、Googleその他の第三者AI事業者が提供、推奨、運営する公式製品ではありません。
