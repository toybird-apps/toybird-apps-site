Prompt Ready

プライバシーポリシー

最終更新日：2026年9月21日

Prompt Readyは利用者のプライバシーを尊重します。このポリシーでは、Windows/macOS版とChatGPT版のPrompt Readyにおける情報の取り扱いを説明します。

Windows / macOS版

デスクトップ版で入力した文章やテーマ、作成した依頼文は端末内で処理されます。Prompt Readyがその内容をToybird Labsのサーバーや外部AIサービスへ自動送信することはありません。

貼り付け操作を選んだ場合はクリップボードの文章を読み取り、コピー操作を選んだ場合は作成した依頼文をクリップボードへ書き込みます。クリップボード履歴は保存しません。

ChatGPT版

ChatGPT版はChatGPT内で動作します。ワークフローを選び、内容を送信した場合、その情報はChatGPT上で会話を続けるために処理されます。

Toybird Labs独自のPrompt Readyアカウントは必要ありません。また、入力した本文、作成された指示内容、ChatGPTの回答をToybird Labsのユーザーデータベースへ意図的に保存しません。

ChatGPT上で処理される情報には、OpenAIの利用規約およびプライバシーポリシーが適用されます。

端末内・ローカルに保存する設定

利用する版に応じて、表示言語、ワークフローの条件、出力言語、初回案内の完了状態、最近使用したワークフローIDの短い一覧など、必要最低限の設定を端末またはChatGPT画面で利用可能なローカルストレージへ保存することがあります。

Recentは、入力した本文やChatGPTの回答ではなく、ワークフローを識別するためのIDを保存する設計です。

アカウント、広告、分析

Prompt ReadyはToybird Labs独自のアカウント登録やログインを必要としません。ChatGPT版は無料で利用できる形を予定しており、Prompt Readyの画面内に第三者広告を表示しません。利用行動を広告目的でプロファイルする広告SDKも使用しません。

インフラと技術ログ

Prompt ReadyはCloudflareなどのホスティング・配信事業者を利用する場合があります。これらの事業者はサービス提供のため、一般的なネットワーク、セキュリティ、運用上のメタデータを処理することがあります。Toybird Labsは、Prompt Readyへ入力した内容を利用者プロファイルの作成に利用しません。

第三者サービス

Prompt ReadyではChatGPT、Claude、Geminiなどのサービス名を案内することがあります。各サービスはそれぞれの事業者が提供しており、利用時には各事業者の利用規約とプライバシーポリシーが適用されます。

Prompt ReadyはToybird Labsが独立して提供する製品であり、OpenAI、Anthropic、Googleその他の第三者AI事業者が提供、推奨、運営する公式製品ではありません。

ポリシーの更新

機能やデータの取り扱いが変わった場合、このポリシーを更新することがあります。更新日はこのページに表示します。
