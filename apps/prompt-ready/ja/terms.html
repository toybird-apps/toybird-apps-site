Prompt Ready

利用規約

適用開始日：2026年9月21日

本利用規約は、Windows/macOS版およびChatGPT版を含むPrompt Readyの利用に適用されます。Prompt Readyを利用することにより、本規約に同意したものとみなされます。

サービス内容

Prompt Readyは、AIサービスをより効率的に利用するためのワークフローテンプレート、構造化された依頼文の作成支援、関連するユーザーインターフェースを提供します。機能は利用するプラットフォームによって異なり、今後変更される場合があります。

無料提供と提供状況

Prompt Ready for ChatGPT v1.0は、Prompt Ready独自のサブスクリプション料金なしで提供する予定です。Toybird Labsは、将来、機能や提供方法の変更、一時停止、終了を行う場合があります。

利用者の責任

入力する情報、AIサービスへ送信する指示、生成された結果の利用については利用者自身が責任を負います。AIが生成した内容には、不完全、不正確、または特定の用途に適さない情報が含まれる可能性があります。重要な用途では、必ず内容を確認してください。

禁止事項

法令に違反する行為、第三者の権利を侵害する行為、サービスやインフラの妨害、不正アクセスの試み、悪意あるコンテンツの配布などにPrompt Readyを利用してはなりません。

第三者サービス

Prompt Readyは、ChatGPT、Claude、Geminiなど第三者が提供するサービスと組み合わせて利用される場合があります。第三者サービスの利用には、それぞれの事業者の規約およびポリシーが適用されます。Toybird Labsは、第三者サービスの提供状況、動作、生成結果について責任を負いません。

知的財産

Prompt Readyのソフトウェア、インターフェース、ブランド、独自のワークフロー内容に関する権利は、Toybird Labsまたは正当な権利者に帰属します。本規約により、それらの所有権が利用者へ移転することはありません。

保証の否認

Prompt Readyは、法令で認められる範囲で「現状有姿」かつ「提供可能な状態」で提供されます。Toybird Labsは、常時利用可能であること、エラーが発生しないこと、AI生成結果が正確であることを保証しません。

責任の制限

適用法令で認められる範囲で、Toybird Labsは、Prompt Readyまたは第三者サービスの利用に関連して生じた間接的、付随的、特別、結果的その他これらに類する損害について責任を負いません。

規約の変更

サービス内容、法令、運用環境の変更に応じて、本規約を更新する場合があります。重要な変更を行った場合は、このページの適用開始日を更新します。

準拠法・管轄

本規約は日本法に準拠します。協議によって解決できない紛争については、適用法令で認められる範囲で、東京の裁判所を管轄裁判所とします。
